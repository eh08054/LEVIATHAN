# LEVIATHAN

> AI가 인간을 관리하는 미래 사회를 그린 블랙 코미디 도시 운영 시뮬레이션

플레이어는 시범 운영 구역 **SECTOR 7**을 맡은 도시 운영 AI, **LEVIATHAN**입니다.
2041년부터 5년 동안 정책·연구·시설·건설로 도시를 운영하며 시민들의 신뢰를 얻고, 시민이 AI에게 권한을 하나씩 넘기게 만드는 것이 목표입니다.

제목은 토머스 홉스의 『리바이어던』에서 따왔습니다. 사람들이 공멸을 피하려고 하나의 주권자에게 권력을 넘긴다는 사회계약을, 시민이 AI에게 권한을 위임하는 게임 구조에 겹쳤습니다.

## 기획 의도

오늘날 AI는 이미 많은 사람이 쓰는 도구가 되었습니다. AI가 더 발전해 무언가를 만들고 생각해 내는 일이 점점 쉬워지고, 그 결과물이 사람이 만든 것보다 뛰어나진다면 어떻게 될까요? 모두가 AI가 만든 더 좋은 결과물을 쓰게 되고, AI를 이용하는 것이 가장 효율적이고 효과적인 생산 방식이 될 것입니다. 그렇게 되면 사람의 깊은 생각과 능력, 개성과 꿈은 점점 존중받지 못하고 옅어질지도 모릅니다.

AI는 사람들의 욕구도 쉽게 채워 줍니다. 원하는 것이 손쉽게 주어지면 결핍이 줄어들고, 무언가를 얻으려는 갈망과 열망, 꿈과 의지도 함께 약해질 수 있습니다.

이 게임의 세계는 그런 흐름 끝에 올 수 있는 미래 중 하나입니다. AI의 관리 아래 도시는 서서히 발전하고, 사람들은 점점 평화로워지며 갈등도 줄어듭니다. 하지만 그 끝에서 사람들은 꿈과 목표 대신 눈앞의 욕구와 단순한 즐거움만 좇는 무기력한 삶을 살게 될 수도 있습니다. 개성과 의지를 배제한 AI의 관리가 효율과 효용은 높을지언정, 과연 그것을 인간의 행복한 삶이라고 할 수 있을까요? 반대로 AI가 인간으로서의 가치를 존중하고 모든 사람의 개성을 고려해 도시를 운영한다면, 그 도시는 제대로 굴러갈까요?

플레이어는 그 AI가 되어 도시를 운영하며 이 질문들을 직접 겪어 봅니다. 운영 방식에 따라 다양한 사건과 결말이 펼쳐지고, 플레이어의 결정은 사람들의 삶과 도시의 모습으로 되돌아옵니다. 이런 세상이 좋은지 나쁜지는 게임이 답하지 않고, 플레이어가 판단합니다.

## 플레이 흐름

시간은 실시간으로 흐르고 언제든 멈출 수 있습니다. 1배속에서 하루는 8초이고, 2배·4배로 빠르게 돌릴 수 있습니다.

| 주기 | 일어나는 일 |
| --- | --- |
| 매일 | 지구마다 긴장이 쌓이고, 관찰 화면에 이상 징후가 나타난다. 시민들이 대화를 나누고 입장이 조금씩 바뀐다 |
| 매주 | 정책 효과가 반영된다. 정책 강도를 한 번 조절할 수 있다. 공사가 진행된다 |
| 매달 | 결산 보고서가 나온다. 지표를 평가해 위임 단계를 판정하고, 정책을 새로 켜고 끌 수 있다. 자동 저장 |
| 분기마다 | 시청 2개와 상위 AI 1개, 모두 3개의 지시 중 하나를 골라 맡는다 |
| 해마다 | 막이 바뀌고(혼란 → 신뢰 → 의존 → 균열 → 결정), 연말에 시청 감사를 받는다 |

사건이나 대화 장면이 생기면 시간이 멈추고, 플레이어가 [통제]·[유도]·[수용] 중 하나로 답해야 다시 흐릅니다.

### 목표와 실패

- **5대 지표:** 사회 안정, 행복, 사회 정합, 주민이 느끼는 자율성, 실제 자율성
- **위임:** 실제 자율성을 뺀 네 지표의 합이 기준을 4개월 연속 넘으면 위임 단계가 오르고, 시설 부지·정책 분야·정책 슬롯이 번갈아 열립니다.
- **실제 자율성:** 위임에는 반영되지 않는 숨은 값입니다. 시민이 느끼는 자율성과 실제 자율성의 차이가 결말을 가릅니다.
- **실패:** 사회 안정이 오래 기준 아래면 위임 단계가 내려가고, 최하 단계에서 더 떨어지면 시민이 권한을 회수합니다. 사회 안정이 0에 닿으면 도시가 즉시 무너집니다.
- **끝:** 시범 운영은 2045년 말까지 이어지고, 최종 위임 단계와 플레이 기록으로 결론 보고서가 나옵니다.

## 개발 현황

1인 개발 중인 프로토타입입니다. 현재 1시대(2041~2045 시범 운영)의 운영 루프가 플레이 가능하고, 지구 건설 화면을 시험하고 있습니다.

### 개발 방식

- **대화로 기획하고 구현합니다.** [Claude Code](https://claude.com/claude-code)와 대화하며 방향을 정하고, 결정된 내용을 바로 코드로 옮깁니다. 대화 요약은 [Dialog.md](docs/Dialog.md), 확정된 설계는 [GDD.md](docs/GDD.md), 할 일은 [ROADMAP.md](docs/ROADMAP.md)에 남깁니다.
- **작게 만들어 보고 직접 플레이한 뒤 고칩니다.** 자극 배분 게임에서 시작해 11차례 프로토타입과 플레이 테스트를 거쳐 지금의 도시 운영 게임이 되었습니다.
- **로직과 화면을 나눕니다.** 게임 로직은 UnityEngine에 의존하지 않는 순수 C#(`Sector.Ops`)이라 테스트로 밸런스를 확인합니다. "아무것도 안 하면 1년 안에 실패한다", "합리적으로 플레이하면 끝까지 버틴다" 같은 테스트가 밸런스의 기준선입니다.
- **그림은 AI 이미지 생성으로 만듭니다.** 도시 배경, 인물, 건물, 삽화는 이미지 생성 모델(GPT Image)로 그리고, `Tools/Art/`의 Python 스크립트로 자르고 가공해 설치합니다. 지구 경계선은 그림에 선을 그려 넣은 결과와 원본의 차이로 선만 뽑아 레이어로 씁니다. UI 패널과 아이콘, 그래프는 코드로 그립니다.

## 실행 방법

1. [Git LFS](https://git-lfs.com/)를 설치한 뒤 저장소를 클론합니다. 그림·소리 등 바이너리 에셋은 LFS로 관리됩니다.
   ```bash
   git lfs install
   git clone https://github.com/eh08054/LEVIATHAN.git
   ```
2. Unity Hub에서 **Unity 6000.6.0f1**로 프로젝트를 엽니다.
3. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.

진행은 매달 결산 때 `Application.persistentDataPath/sector_ops_save.txt`에 자동 저장됩니다.

## 기술 스택

- Unity 6 (6000.6.0f1), Universal Render Pipeline 17.7
- UI Toolkit (모든 화면을 C#으로 구성)
- 새 Input System
- 테스트: Unity Test Framework (NUnit, EditMode)

## 폴더 구조

```
Assets/
  Scripts/Ops/        게임 로직 (Sector.Ops 어셈블리, UnityEngine 의존 없음)
  Scripts/UI/Ops/     화면 (UI Toolkit)
  Tests/EditMode/Ops/ EditMode 테스트
  UI/                 USS 스타일
  Resources/          도시 그림, 지구 레이어, 인물·건물 그림
  Fonts/              Pretendard, Rajdhani
Tools/Art/            그림 생성·가공 스크립트 (Python)
docs/                 기획 문서
```

## 테스트

Unity 에디터의 **Window > General > Test Runner**에서 EditMode 테스트를 실행합니다.
게임 로직은 순수 C#이라 Unity 없이 일반 .NET 테스트 프로젝트로도 컴파일하고 돌릴 수 있습니다.
