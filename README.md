# LEVIATHAN

> AI가 인간을 관리하는 미래 사회를 그린 블랙 코미디 도시 운영 시뮬레이션

플레이어는 세계연합의 시험 도시 **섹터 알파(Sector α)**를 운영하는 AI, **LEVIATHAN**입니다.
2071년부터 5년 동안 정책 결정, 시설 건설, 연구 등 다양한 작업을 하며 도시를 운영합니다. 게임의 최종 목표는 사람들이 모든 권한을 AI에게 위임하도록 하는 것입니다.

제목은 토머스 홉스의 『리바이어던』에서 따왔습니다. 사람들이 서로 해치는 것을 막기 위해 하나의 주권자에게 권력을 넘긴다는 홉스의 사회계약을, 사람들이 AI에게 권한을 넘기는 이 게임의 구조에 빗댔습니다.

## 기획 의도

오늘날 AI는 이미 많은 사람이 쓰는 도구가 되었습니다. AI가 더 발전해 무언가를 만들고 생각해 내는 일이 점점 쉬워지고, 그 결과물이 사람이 만든 것보다 뛰어나진다면 어떻게 될까요? 모두가 AI가 만든 더 좋은 결과물을 쓰게 되고, AI를 이용하는 것이 가장 효율적이고 효과적인 생산 방식이 될 것입니다. 그렇게 되면 사람의 깊은 생각과 능력, 개성과 꿈은 점점 존중받지 못하고 옅어질지도 모릅니다.

AI는 사람들의 욕구도 쉽게 채워 줍니다. 원하는 것이 손쉽게 주어지면 결핍이 줄어들고, 무언가를 얻으려는 갈망과 열망, 꿈과 의지도 함께 약해질 수 있습니다.

이 게임의 세계는 그런 흐름 끝에 올 수 있는 미래 중 하나입니다. AI의 관리 아래 도시는 서서히 발전하고, 사람들은 점점 평화로워지며 갈등도 줄어듭니다. 하지만 그 끝에서 사람들은 꿈과 목표 대신 눈앞의 욕구와 단순한 즐거움만 좇는 무기력한 삶을 살게 될 수도 있습니다. 개성과 의지를 배제한 AI의 관리가 효율과 효용은 높을지언정, 과연 그것을 인간의 행복한 삶이라고 할 수 있을까요? 반대로 AI가 인간으로서의 가치를 존중하고 모든 사람의 개성을 고려해 도시를 운영한다면, 그 도시는 제대로 굴러갈까요?

플레이어는 그 AI가 되어 도시를 운영하며 이 질문들을 직접 겪어 봅니다. 운영 방식에 따라 다양한 사건과 결말이 펼쳐지고, 플레이어의 결정은 사람들의 삶과 도시의 모습으로 되돌아옵니다. 이런 세상이 좋은지 나쁜지는 게임이 답하지 않고, 플레이어가 판단합니다.

## 주요 시스템

| 시스템 | 내용 |
| --- | --- |
| 지표와 위임 | 행복, 사회 안정 등 다섯 가지 지표를 기준 이상으로 유지하면 권한을 한 단계씩 넘겨받습니다. |
| 정책 | 9개 분야마다 통제 정책과 유도 정책이 있고, 강도를 조절할 수 있습니다. 함께 쓰면 효과가 커지거나 부딪히는 정책도 있습니다. |
| 연구 | 4개 분야에 8개씩 있고, 3단계와 5단계에서는 둘 중 하나의 노선을 골라야 합니다. 연구할 때마다 AI가 사람에게서 일을 하나씩 넘겨받습니다. |
| 도시와 구역 | 도시는 11개 구역으로 나뉘고, 구역마다 성격과 어울리는 시설이 다릅니다. |
| 긴장과 사건 | 불만이 쌓이면 수군거림, 모임, 계기를 거쳐 사건이 됩니다. 해마다 미리 예보되는 위기도 있습니다. |
| 관찰 | 도시 전체를 한눈에 보는 화면과 구역별 카메라로 이상 징후를 찾아 분석하고 대응합니다. |
| 이야기 | 5막으로 이어지고, 해마다 감사를 받으며 분기마다 지시를 고릅니다. 고정 시민 10명의 생각이 플레이에 따라 바뀝니다. |

이 게임의 중심은 건설이 아니라 **관찰**입니다. 내 정책과 결정에 따라 도시와 사람들이 어떻게 달라지는지 지켜보는 게임입니다.

## 플레이 흐름

시간은 실시간으로 흐르고 언제든 멈출 수 있습니다. 1배속에서는 하루가 8초이고, 2배속과 4배속으로 빠르게 돌릴 수 있습니다.

| 주기 | 일어나는 일 |
| --- | --- |
| 매일 | 구역마다 긴장이 쌓이고 관찰 화면에 이상 징후가 나타납니다. 시민들은 서로 이야기하며 생각이 조금씩 바뀝니다. |
| 매주 | 정책의 효과가 반영되고, 정책 강도를 한 번 바꿀 수 있습니다. |
| 매달 | 결산 보고서가 나옵니다. 지표에 따라 위임 단계가 정해지고, 이때 정책을 새로 시행하거나 멈출 수 있습니다. 게임은 이때 자동 저장됩니다. |
| 분기마다 | 세계연합의 지시 2개와 상위 AI의 지시 1개 중 하나를 골라 수행합니다. |
| 해마다 | 이야기의 막이 바뀌고(혼란, 신뢰, 의존, 균열, 결정), 연말에 세계연합의 감사를 받습니다. |

사건이나 대화 장면이 생기면 시간이 멈춥니다. 통제, 유도, 수용 중 하나로 답하면 다시 시간이 흐릅니다.

### 목표와 실패

- **지표:** 행복, 사회 안정, 사회 정합, 체감 자율성, 실제 자율성의 다섯 가지입니다.
- **위임:** 실제 자율성을 뺀 네 지표의 합이 4개월 연속 기준을 넘으면 위임 단계가 오릅니다. 단계가 오를 때마다 시설 부지, 정책 분야, 정책 칸이 차례로 늘어납니다.
- **실제 자율성:** 위임 판정에는 쓰이지 않는 숨은 값입니다. 사람들이 체감하는 자율성과 실제 자율성이 얼마나 벌어졌는지가 결말을 가릅니다.
- **실패:** 사회 안정이 오래 낮으면 위임 단계가 내려가고, 가장 낮은 단계에서 더 떨어지면 권한을 빼앗깁니다. 사회 안정이 0이 되면 도시는 바로 무너집니다.
- **끝:** 운영은 2075년 말까지 이어지고, 마지막 위임 단계와 지금까지의 기록으로 결과 보고서가 나옵니다.

## 개발 현황

혼자 개발하고 있는 프로토타입입니다. 5년 운영은 처음부터 끝까지 플레이할 수 있고, 지금은 화면(메인 화면, 도시 그림, 3D 모형, 관찰 화면)을 새로 만들고 있습니다.

### 개발 방식

- **대화로 기획하고 바로 구현합니다.** [Claude Code](https://claude.com/claude-code)와 이야기하며 방향을 정하고, 정해진 내용을 곧바로 코드로 옮깁니다. 대화 내용은 [Dialog.md](docs/Dialog.md)에, 확정된 설계는 [GDD.md](docs/GDD.md)에, 할 일은 [ROADMAP.md](docs/ROADMAP.md)에 정리합니다.
- **작게 만들고 직접 해 본 뒤 고칩니다.** 처음에는 자극을 나눠 주는 게임이었는데, 11번의 프로토타입과 플레이 테스트를 거쳐 지금의 도시 운영 게임이 되었습니다.
- **게임 로직과 화면을 나눕니다.** 게임 로직은 Unity에 의존하지 않는 순수 C#(`Sector.Ops`)이라 테스트로 밸런스를 확인할 수 있습니다. "아무것도 하지 않으면 1년 안에 실패한다", "합리적으로 플레이하면 끝까지 버틴다" 같은 테스트가 밸런스의 기준입니다.
- **3D 모형을 먼저 만들고 그 위에 그림을 그립니다.** 도시 배치는 Unity 3D 모형(`Assets/ModelCity`)을 기준으로 합니다. 모형을 찍은 화면을 이미지 생성 모델(GPT Image)에 구도로 넘겨 도시 그림을 그립니다. 인물, 관찰 화면의 거리, 삽화, 건물 외벽도 GPT Image로 그리고 `Tools/Art/`의 Python 스크립트로 다듬어 넣습니다.
- **화면은 시안부터 만듭니다.** 브라우저용 HTML 시안(`Tools/Art/proto/`)으로 모양을 먼저 정한 뒤 Unity의 UXML/USS로 옮깁니다.

## 실행 방법

1. [Git LFS](https://git-lfs.com/)를 설치하고 저장소를 클론합니다. 그림과 소리 같은 파일은 LFS로 관리합니다.
   ```bash
   git lfs install
   git clone https://github.com/eh08054/LEVIATHAN.git
   ```
2. Unity Hub에서 **Unity 6000.6.0f1**로 프로젝트를 엽니다.
3. `Assets/Scenes/SampleScene.unity`를 열고 Play를 누릅니다.

게임은 매달 결산 때 `Application.persistentDataPath/sector_ops_save.txt`에 자동 저장됩니다.

## 기술 스택

- Unity 6 (6000.6.0f1), Universal Render Pipeline 17.7
- UI Toolkit (UXML/USS와 C#)
- 새 Input System
- 테스트: Unity Test Framework (NUnit, EditMode)

## 폴더 구조

```
Assets/
  Scripts/Ops/        게임 로직 (Sector.Ops 어셈블리, UnityEngine 의존 없음)
  Scripts/UI/Ops/     화면 (UI Toolkit)
  Tests/EditMode/Ops/ EditMode 테스트
  ModelCity/          3D 도시 모형과 그 HUD
  UI/                 USS 스타일
  Resources/          도시 그림, 블록·인물 그림, 화면 UXML
  Fonts/              Pretendard, Rajdhani
Tools/Art/            그림 생성·가공 스크립트 (Python)
docs/                 기획 문서
```

## 테스트

Unity 에디터의 **Window > General > Test Runner**에서 EditMode 테스트를 실행할 수 있습니다.
게임 로직은 순수 C#이라 Unity 없이 일반 .NET 테스트 프로젝트로도 돌릴 수 있습니다.
